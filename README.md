# Budget Tracker

A full-stack personal finance application built with Java and Spring Boot that helps users manage budgets and track expenses securely.

## Features

- User authentication
- Budget management
- Expense tracking
- Responsive UI
- PostgreSQL integration

## Tech Stack

- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- Hibernate
- PostgreSQL
- Thymeleaf
- HTML
- CSS
- JavaScript
- Maven
